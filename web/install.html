数据库配置

本项目只支持 PostgreSQL。用的是 DISTINCT ON、 ON CONFLICT、部分索引等 PG 专有语法，SQLite / MySQL 跑不起来。
数据库需要提前创建好。安装程序只建表，不会替你建库。
命令行示例：createdb -U postgres ltzy

站点信息

这些内容会显示在前端首页与页头，装完之后也能在管理后台改。
出现在浏览器标题、首页 Hero 和页头
用于生成登录链接、支付回调地址。留空则按当前访问地址自动推断
可填相对路径或完整 URL。留空用默认文字 Logo

管理员账户

这个账号拥有最高权限，可以管理渠道、定价、用户。请务必改掉默认密码。
至少 6 位
安装完成后：本页面会自动失效（访问 /install 返回 404）， 所有前端页面开放访问。若使用 Swoole 常驻服务，需要重启服务让新配置生效。

✓ 安装完成

站点已就绪。记得做这两件事：
1. 重启服务
systemctl restart llm-gateway　（若用 PHP-FPM 则 systemctl reload php-fpm）
不重启的话，正在运行的进程还在用旧配置。
2. 收好管理员密码
用户名已按你填的创建。忘记只能进服务器用 php bin/set-admin.php 重置。
